Known going in

The RIOs passed all four tasks and left these open. They are not cases; note them if you hit them.

stream
If the stream route answers an error (not a dropped connection) the page stops updating and says nothing. A restart (case sh5) is the path that does fall back.
trouble
A long trouble line under the word pushes pause and stop below the fold; its "try landing it again" is offered even when paused.
sessions
A failed attach clicked twice stacks two "could not attach" wells; a walkthrough being written has no way to watch its session.
copy
One em-dash survives in the pre-approval plan heading, between Milestone n and its title; it only shows before a plan is approved.
not walked
The second gate (close and land) only shows at review; this mission is flying, so it is not a case here.

The milestone's done check

The done-when, run as written
Setup

Save this as /tmp/check.js (it is not in the repo):

(() => {
  const q = (s) => [...document.querySelectorAll(s)];
  const anchors = q("#rail a[href^='#']").map((a) => a.hash);
  const word = document.querySelector("#word")?.textContent.trim() ?? "";
  const steps = q("#plan details.step").map((d) => ({
    milestone: d.querySelector("summary h3")?.textContent.trim(),
    tasks: d.querySelectorAll("li[data-task]").length,
    intents: [...d.querySelectorAll("li[data-task] .i")].filter((i) => i.textContent.trim()).length,
  }));
  const feed = q("#progress .prog-feed li.prog-entry").length;
  const failed = q("section .mv-empty").map((p) => p.textContent).filter((t) => /did not load/.test(t));
  return JSON.stringify({ anchors: anchors.length, list: anchors, word, steps, feed, failed }, null, 1);
})()
Steps
  1. In the integration worktree: node tools/cdp.mjs "http://localhost:8767/mission.html?project=maverick&mission=mission-page-and-inbox" --eval /tmp/check.js --wait 7000
  2. grep -rnE 'window\.(prompt|confirm)' web/mission*
  3. npm run lint
Expected
  • anchors: 4 (#ask #plan #progress #result), a non-empty word, four steps whose intents equal their tasks (3, 4, 2, 3), feed above zero, failed: [].
  • The grep prints nothing (exit 1).
  • Lint exits 0. (It is node --check only: a syntax pass.)
